## ✨ Features

- **Obsidian & Champagne Gold Aesthetic**: Dark studio branding inspired by Porsche, Mercedes-AMG, and Bugatti.
- **100% INR Currency & Localized Financials**: Prices in ₹ Lakhs & ₹ Crores with RTO tags (`DL-01`, `HR-26`, `UP-16`).
- **Interactive 360° Studio Viewer**: Interactive rotation angle viewer for luxury inventory.
- **Dealership Executive Analytics Portal**: Real-time sales telemetry dashboard with visual SVG charts.
- **Bespoke EMI Calculator**: Calculated with top Indian banking partners (HDFC, ICICI, Axis, SBI).
- **Valuation & Instant Buyout Wizard**: 4-step digital valuation engine for trade-in sellers.
- **Wishlist & Side-by-Side Comparison Engine**: Compare specifications across up to 3 cars.

---

## 🛠 Tech Stack

- **Core**: React 18 + Vite 8
- **Styling**: Tailwind CSS v4 + @tailwindcss/vite
- **Icons**: Lucide React
- **Deployment**: Vercel CI/CD
